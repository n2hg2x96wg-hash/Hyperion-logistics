# Freight showcase photo

The homepage freight section (`#freight` in `index.html`) uses the container-ship photo in this folder. If a photo
fails to load, the original illustration `assets/hero/freight-ship.svg` is shown instead.

**Files** (generated from the owner-supplied picture, photo area only, 1179×880, never upscaled):
- `ship-960.*`, `ship-1179.*` (AVIF, WebP, JPEG) for tablets and desktops
- `ship-mobile-720.*`, `ship-mobile-1080.*`: the same 4:3 frame for phones

The supplied picture had route labels, a ship name and a "status / ETA" box printed on it. Those were blurred out so
the page never shows invented shipment details; the faint light lines on the water remain as decoration.

**Replacing the photo:** use a landscape container-ship photo, ideally 2400 px wide or more, without printed text,
and licensed for a commercial website. Regenerate the same file names and update `CREDITS.md`.
