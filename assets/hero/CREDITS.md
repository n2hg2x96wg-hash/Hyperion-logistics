# Homepage hero picture (internal record)

The homepage hero (`.hero3-media` in `ui/site-v2.css`) and the band on the tracking pages (`.track-band`) use this
photograph. This file is a record for the site owner; it is not linked from the site.

| Files | Source (Wikimedia Commons file page) | Author | Licence |
| --- | --- | --- | --- |
| `port-*` (`port-1280/1920/2560`, `port-mobile-1080`; AVIF, WebP, JPEG) | [HMM Dublin (ship, 2020) IMO 9863314, Port of Rotterdam pic1.JPG](https://commons.wikimedia.org/wiki/File:HMM_Dublin_(ship,_2020)_IMO_9863314,_Port_of_Rotterdam_pic1.JPG) | Alf van Beem | CC0 1.0 (public domain dedication) |

CC0 requires no attribution, so the page shows no credit line. The licence was read from the file page on 2026-10-25.
The files were made from Commons' 3840 px rendition: the desktop sizes are a 16:9 crop of the ship, cranes and water;
`port-mobile-1080` is a wider crop of the ship alone for the band at the top of the hero on phones. Metadata is
stripped. The vessel's operator name on the hull remains a trademark of its owner; the photo is decorative and says
nothing about any Hyperion shipment.

The dark theme tones the photo down with a CSS filter so the headline stays readable; the light theme shows it as is.

## Replacing the photo

Use only a photo you own, one licensed to Hyperion Logistics for this use, or one in the public domain / under CC0,
landscape and at least 2560 px wide. Regenerate the same file names and update this table.
